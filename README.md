# dabh.gg downloads

Your games, friends, servers and mods in one app.

**[Download dabh.gg for Windows](https://github.com/yusufmuhammed00199-collab/dabh-gg-releases/releases/latest/download/dabh-gg-setup.exe)**

Every version, with the Linux `.AppImage` and `.deb`, is on the [releases page](https://github.com/yusufmuhammed00199-collab/dabh-gg-releases/releases).

Windows may say it protected your PC, because the app isn't code signed yet: click **More info**, then **Run anyway**. After that, dabh.gg updates itself: press **Update** in the app when it shows.

This repository only holds the installers; installed apps check it for updates.
